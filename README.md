# nr/ux — portfolio, Nov 2026 · V3

**Brand:** "Human in the loop." Bone paper `#ece9e2`, ink `#0c0c0d`, one electric ultramarine `#2b1cff`.
Archivo everywhere (its width axis is the "elastic" brand voice). Geist Mono appears only inside terminal windows and code. No italics, no eyebrows, numbers set bold (class `n`).

Static HTML generated by one Node script. No framework, nothing to install.

## Edit → build → preview

```bash
node build.mjs              # regenerates every page
open index.html             # preview locally (or: npx serve .)
```

- No years, no index numbers. Copy stays short; leave `brief`, `move` and `stats` out when there is nothing real to say.

## Add a project

1. Copy any block in `src/projects.mjs` and change the `slug`.
2. Make its media (see below) into `media/<slug>/`.
3. `featured: true` puts it on the homepage and in the hero's prompt console.
4. `node build.mjs`.

## Add a video

```bash
# 8s muted loop + poster (+ full film with sound)
node tools/make-media.mjs "/path/to/master.mp4" my-slug --start 12 --poster 20 --film
```

Then in the project:

```js
cover: { type: "video", src: "media/my-slug/loop.mp4", poster: "media/my-slug/poster.jpg" },
film:  { src: "media/my-slug/film.mp4", poster: "media/my-slug/poster.jpg" },
// or host it on YouTube/Vimeo instead of a file:
embed: "https://www.youtube.com/embed/VIDEO_ID",
```

A video can also go inside any chapter: `media: { type: "video", src, poster }`.

**Process reels on the Lab page:** create `src/reels.json`:

```json
[{ "title": "Building Driftly with Claude Code", "src": "media/reels/driftly.mp4", "poster": "media/reels/driftly.jpg" }]
```

The section only appears when that file has entries.

## Record a live interaction (animations, hovers, clicks)

```bash
node tools/record.mjs "/path/to/page.html" my-slug hero --secs 9
node tools/record.mjs "/path/to/page.html" my-slug nav --h 640 --secs 9 \
  --actions '[{"wait":800},{"hover":".nav__item:nth-child(1) .nav__link"},{"wait":1800}]'
node tools/record.mjs "/path/to/page.html" my-slug mobile --w 390 --h 844 --secs 12 --actions '[{"wait":3000},{"scroll":700}]'
```

Writes `media/<slug>/<name>.mp4` + a poster `.jpg`. Uses Chrome's own screencast, so frames are exact.
In a project, a recording that is not 16:10 takes a `ratio`, e.g. `{ type: "video", src, poster, ratio: "1440 / 640" }`.
`{ type: "phone", src }` puts a video (or a tall screenshot that scrolls) inside a phone frame.
A chapter's `media` can be a list to show several side by side. A project's `films` list shows full films with sound.

## Add a scrolling site capture

```bash
node tools/capture-page.mjs https://example.com my-slug        # → media/my-slug/site.jpg
node tools/capture-page.mjs ./local/page.html my-slug app      # → media/my-slug/app.jpg
```

Use it as `cover: { type: "site", src: "media/my-slug/site.jpg" }`. It auto-scrolls in a browser frame.
